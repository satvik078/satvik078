`ViT-Base/16` `PyTorch` `HuggingFace` `MTCNN` `Flask` `SQLAlchemy` `PostgreSQL` `SafeTensors`

---

### 🔍 Customer Feedback Sentiment Analysis Platform
Production-ready AI platform using **BERT** to classify customer reviews with confidence scores. Supports manual text input, CSV batch upload, and real-time API-based review fetching with a full analytics dashboard.

`BERT` `HuggingFace` `Streamlit` `Plotly` `Pandas` `Render`

### 📄 RAGify — Chat with Your Documents
A **Retrieval-Augmented Generation** system that lets users upload PDFs and query them in natural language. Retrieves relevant chunks from a vector database and generates cited answers using GPT-4o-mini or Qwen.

`LangChain` `OpenAI` `Qwen` `pgvector` `Supabase` `sentence-transformers` `PyPDF`

`TinyLlama-1.1B` `LoRA` `HuggingFace` `Parameter-efficient fine-tuning`
